# 矩阵乘法优化
native.cu -> 朴素实现

smem_tile.cu-> 
引入了共享内存和分块机制，相比于朴素版本极大降低了全局内存的访问次数，极大提高了处理效率。

thread_tile.cu ->
相比于上一个版本，将每一步计算的向量内积转换为向量外积的形式，极大提高了计算访存比，减少了对共享内存的频繁访问。

thread_tile_opt.cu -> 
引入了float4向量化读取和swizzle技术，避免了银行冲突。

warp_tile.cu ->
在上一个版本的基础上，进一步实现了warp tile的逻辑，细化了warp的调度逻辑，上限更高。

warp_tile_double_buffer.cu ->
在上一版本的基础上，引入了双缓冲，能够将计算时间与数据搬运时间重叠，更好的进行延迟隐藏，但会加大对共享内存的使用，可能导致SM上的线程活跃度下降。

cpasync.cu ->
引入了安培架构特有的cp.async指令，减少了搬运数据过程中寄存器的使用，进一步提高了性能

tc.cu ->
引入了tensor core api加速矩阵乘法
