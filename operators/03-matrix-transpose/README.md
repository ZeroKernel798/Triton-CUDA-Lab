# 矩阵转置优化
native.cu -> 朴素实现

shared_mm.cu-> 
矩阵转置优化的关键在于访存的优化。这一版本引入了共享内存，首先解决了读写的访问合并。其次是通过padding操作解决了银行冲突

flattened_float4.cu ->
跟float4.cu的优化思路类似，但改变了看待输入数据的视角，避免了每行可能都要处理数据不足4个的情况，减少判断逻辑，提高效率

shared_mm_ILP.cu -> 
这一版本增加了指令级并行度 (ILP)。一个线程连续发射多个访存请求，可以更好地隐藏内存延迟，并且减少每块的线程数有时能提高硬件的活跃 Warp 数，让调度器更灵活。
